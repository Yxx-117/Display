# 研发流程

## 文档维护流程

1. 在对应主题目录下新增或修改 Markdown
2. 本地预览确认渲染正常
3. 执行 `python update_docsify_readmes.py` 刷新导航
4. 提交并推送到 `main`
5. GitHub Actions 自动部署，可在 Actions 页面查看进度

## 分支约定

| 分支 | 用途 |
| --- | --- |
| `main` | 文档源，Pages 可直接指向此分支 |
| `gh-pages` | 可选，由流水线生成的发布分支 |

## 职责说明

- 文档作者：只维护 Markdown 内容本身
- 导航维护：交给脚本，不手工编辑
- 部署：推送后由 GitHub Actions 完成，无需人工介入
