# 快速开始

本文演示一篇普通文档该怎么写。

## 一、新建文档

在 `docsify_root/` 下找到对应主题目录，直接新建 `.md` 文件即可，例如：

```text
docsify_root/01_产品业务文档/01_快速开始/这是一篇新文档.md
```

## 二、刷新导航

在仓库根目录执行一次：

```bash
python update_docsify_readmes.py
```

脚本会自动重建：

- 各目录的 `README.md` 索引页
- 站点首页 `docsify_root/README.md`
- 侧边栏 `docsify_root/_sidebar.md`

## 三、提交发布

```bash
git add .
git commit -m "docs: 新增快速开始说明"
git push origin main
```

推送完成后 GitHub Actions 会自动重建导航并部署，稍等片刻刷新页面即可看到更新。

## 四、图片怎么放

图片统一放在当前文档所在目录的 `img/` 子目录中，脚本会自动跳过该目录，不会把它当成文档分类。

```markdown
![示意图](./img/demo.png)
```
