# 编写规范

## 标题层级

- 一篇文档只用**一个** `#` 一级标题
- 正文层级使用 `##` / `###` / `####`
- 右侧目录会自动抓取 `##` 到 `#####`，层级要连续，不要跳级

## 命名建议

| 场景 | 建议 |
| --- | --- |
| 文档文件 | 中文短句，避免 `/ \ : * ? " < >` |
| 目录 | 使用 `01_`、`02_` 数字前缀控制排序 |
| 图片 | 放入同级 `img/` 目录，文件名英文或拼音 |

目录名与文件名中的数字前缀只用于排序，在导航里显示时会被自动去掉。

## 需要避免的写法

- 不要手工长期维护 `README.md` 与 `_sidebar.md`，它们由脚本生成
- 不要在文档里写指向本地磁盘的绝对路径
- 不要把大体积图片直接塞进仓库，优先压缩或使用图床
