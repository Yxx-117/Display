# 常见问题

## 页面显示 404

1. 确认文档文件已经 `git push` 到远端
2. 确认部署后执行过 `python update_docsify_readmes.py`
3. 到仓库的 Actions 页面确认部署工作流已跑完

## 侧边栏没有新文档

导航文件是生成物，不是手写物。重新执行脚本并再次提交：

```bash
python update_docsify_readmes.py
git add docsify_root
git commit -m "docs: 刷新导航"
```

## 页面样式丢失或一直转圈

通常是 CDN 资源加载失败。执行本地化脚本后再提交：

```bash
python tools/fetch_vendor.py
git add docsify_root/vendor docsify_root/index.html
git commit -m "chore: 本地化静态资源"
```

## 中文目录名能不能用

能用，脚本生成链接时已对路径做 URL 编码。但为降低风险，建议目录保留 `01_` 这类数字前缀，展示名仍为中文。
