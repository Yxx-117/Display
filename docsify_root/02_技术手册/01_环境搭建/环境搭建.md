# 环境搭建

## 前置条件

- Python 3.9 及以上（仅用于生成导航，不参与站点运行）
- Git

## 本地预览

Docsify 是运行时渲染，用任意静态服务器打开 `docsify_root` 即可：

```bash
cd docsify_root
python -m http.server 3000
```

浏览器访问 <http://localhost:3000>。

> 注意：直接双击 `index.html` 用 `file://` 打开会受浏览器跨域限制，文档读不出来，必须使用 HTTP 服务。

## 目录约定

```text
docsify_root/
├── index.html          # 站点入口，全站唯一 HTML
├── README.md           # 首页（脚本生成）
├── _sidebar.md         # 侧边栏（脚本生成）
├── _coverpage.md       # 封面
└── 01_产品业务文档/     # 数字前缀用于排序
    ├── README.md       # 分类索引（脚本生成）
    └── 01_快速开始/
        ├── README.md   # 目录内索引（脚本生成）
        └── img/        # 图片目录，不参与导航
```
